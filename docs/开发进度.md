## ✅ 已实现

### 1. 项目基础架构

- [x] Tauri 2 + React + TypeScript + Vite 项目初始化
- [x] Rust 后端模块化架构（audio / stt / llm / pipeline / stealth / config）
- [x] TypeScript 前端组件架构（App / FloatingAnswer / Settings）
- [x] 全局 CSS 变量主题系统（深色主题）

- [x] GitHub Actions 自动构建发布（`.github/workflows/release.yml`）
- [x] CLAUDE.md 项目文档

### 2. 音频捕获模块 (`audio/`)

- [x] WASAPI Loopback 系统音频捕获（cpal 库）
- [x] 音频设备枚举（默认输出设备检测）
- [x] 多声道转单声道
- [x] 采样率转换（系统 48kHz → Whisper 要求 16kHz，线性插值）
- [x] VAD 静音检测（webrtc-vad 算法）
- [x] 语音片段切分（可配置阈值）
- [x] 音频缓冲区管理（Arc<Mutex<Vec<f32>>> 共享缓冲区）
- [x] 捕获状态控制（Running / Muted / Idle / Error）
- [x] 静音/取消静音切换

### 3. 语音识别模块 (`stt/`)

- [x] `SttProvider` 统一接口抽象

- [x] Whisper 模型自动下载（从 HuggingFace 下载，临时文件+重命名策略）
- [x] 模型大小选择（tiny / base / small / medium）
- [x] 语言配置（默认 zh）
- [x] OpenAI Whisper API 实现（云端 STT）

### 4. 大模型模块 (`llm/`)

## 已知问题 / 技术债

| 问题 | 说明 | 优先级 |
|------|------|--------|
| whisper-rs 编译依赖重 | 需要 LLVM + CMake，CI 构建时间长 | 中 |
| cpal Stream 的 unsafe Send | 功能正确但不优雅，未来 cpal 可能原生支持 Send | 低 |
| 未使用的代码警告 | `AudioChunk`、`StealthState`、`set_always_on_top` 等未被调用 | 低 |
| LLM 流式输出未真正实现 | `chat_stream` 用同步替代，前端无打字机效果 | 高 |
| 无错误重试机制 | STT/LLM 调用失败后无自动重试 | 中 |
| 配置文件无热更新 | 修改配置后需重启应用 | 低 |
